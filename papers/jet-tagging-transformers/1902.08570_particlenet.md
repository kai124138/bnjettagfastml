# ParticleNet: Jet Tagging via Particle Clouds

- **Authors:** Huilin Qu, Loukas Gouskos
- **Venue / Year:** Phys. Rev. D 101, 056019; 2020 (arXiv 2019)
- **arXiv:** 1902.08570 — https://arxiv.org/abs/1902.08570
- **PDF:** https://arxiv.org/pdf/1902.08570
- **Code:** https://github.com/hqucms/ParticleNet
- **Topic area:** Jet tagging & transformers

## TL;DR
Proposes treating a jet as an unordered **"particle cloud"** (a permutation-invariant set of constituents) and introduces **ParticleNet**, a Dynamic Graph CNN (EdgeConv) adapted from point-cloud learning. It set state-of-the-art on top-tagging and quark/gluon benchmarks and established the particle-cloud representation that later transformer taggers build on.

## Summary
The paper argues that a jet is most naturally represented not as an image or ordered sequence but as an unordered set of its constituent particles — a "particle cloud" — which efficiently captures raw jet information while respecting permutation symmetry. Building on point-cloud deep learning, the authors design ParticleNet, a customized network using Dynamic Graph Convolutional Neural Network (DGCNN) EdgeConv operations that dynamically build a graph over particles in feature space and aggregate local neighborhood information. ParticleNet achieves state-of-the-art performance on two representative jet-tagging benchmarks, improving significantly over prior CNN/RNN/physics-feature methods.

## Key methods / contributions
- **Particle cloud representation**: jet = unordered, permutation-invariant set of constituents; respects symmetry and uses low-level inputs directly.
- **ParticleNet architecture**: stacked **EdgeConv** blocks (from DGCNN) with **dynamic k-NN graphs** recomputed in learned feature space.
- Permutation invariance built in; no jet image binning or particle ordering required.
- Establishes a widely used backbone and the conceptual precursor to transformer-based taggers (ParT).
- Public implementation and pre-trained models released.

## Main results
Achieves state-of-the-art performance on the top-tagging reference dataset and the quark/gluon discrimination benchmark, improving significantly over existing methods at the time (confirmed qualitatively). Specific AUC and background-rejection numbers: see paper.

## Relevance to BNJetTag
ParticleNet **defines the particle-cloud input paradigm** that BNJetTag inherits: our BitNet transformer operates over the same jet-constituent "particle cloud." It is the direct SOTA predecessor to Particle Transformer (the architecture family we binarize), and is one of the canonical full-precision AUC baselines on top tagging and quark/gluon. When we quote "near full precision" for our 1-bit model, ParticleNet/ParT are the reference points. Its EdgeConv graph approach is also a useful contrast to attention when reasoning about which operations are cheapest to map to FPGA LUT/logic.
