# Learned Step Size Quantization

- **Authors:** Steven K. Esser, Jeffrey L. McKinstry, Deepika Bablani, Rathinakumar Appuswamy, Dharmendra S. Modha (IBM Research)
- **Venue / Year:** ICLR 2020
- **arXiv:** 1902.08153 — https://arxiv.org/abs/1902.08153
- **PDF:** https://arxiv.org/pdf/1902.08153
- **Code:** none found (official); multiple community reimplementations exist
- **Topic area:** QAT & binary-NN foundations

## TL;DR
LSQ learns the **quantizer step size (scale)** itself as a trainable parameter via backprop, with a carefully chosen gradient and a step-size learning-rate scaling factor. Applied to weights and/or activations, it set state-of-the-art low-bit accuracy on ImageNet, with 3-bit models reaching full-precision baselines — refining PACT's idea from a clipping bound to the full quantization grid spacing.

## Summary
The paper presents Learned Step Size Quantization, a QAT method that treats the step size of a uniform quantizer as a learnable parameter optimized by backpropagation of the task loss. The key technical choices are: compute the step-size gradient by ignoring the rounding discontinuity (a straight-through-style estimate), and apply a scaling factor to the step-size learning rate so it co-adapts well with the weights. The method needs only a simple modification to existing training code, can be applied per layer to activations or weights at any chosen precision, and achieves the highest ImageNet accuracy to date (at publication) for 2-, 3-, and 4-bit models across several architectures.

## Key methods / contributions
- Make the quantizer **step size / scale** a trainable parameter, learned by gradient descent.
- Define a stable step-size gradient by ignoring the quantizer discontinuity (STE-style) for the round operation.
- Introduce a step-size **learning-rate scaling factor** to balance update magnitudes between step size and weights.
- Simple to add to existing training pipelines; applies uniformly to weights and activations at arbitrary bit-widths.
- Sets SOTA low-precision ImageNet results; 3-bit models reported to match full-precision baselines.

## Main results
On ImageNet across multiple architectures, LSQ reports best-in-class top-1 accuracy at 2/3/4 bits and 3-bit models matching full-precision baselines (exact per-model numbers: see paper).

## Relevance to BNJetTag
LSQ is the most refined member of the "learn the quantization parameters" family that our A8/A6/A4 activation sweep draws on. Where PACT learns a clip bound, LSQ learns the actual grid spacing — the same principle QKeras exposes when scale/step parameters are trained alongside weights. For BNJetTag, LSQ is evidence that very low activation precision can hold accuracy if the step size is learned rather than fixed, supporting our aim of pushing activations to 4–6 bits on top of {−1,+1} weights while preserving tagging AUC. Its STE-based step-size gradient also reuses the same surrogate-gradient machinery (Bengio et al. 1308.3432) underpinning our binary-weight training.
